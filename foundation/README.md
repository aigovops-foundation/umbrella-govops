# Umbrella Foundation Documents

The `foundation/` directory holds the **cross-project program documents** that span Umbrella, Beacon, and any future AiGovOps Foundation project. These are intentionally separate from the Umbrella code/control catalog — they describe **why** the program exists, **what threats** it addresses, **what positions** the Foundation takes publicly, and **when** things ship.

| File | Purpose |
|------|---------|
| [GLOSSARY.md](GLOSSARY.md) | One authoritative definition per term — UCID, control, receipt, EvidenceBundle, etc. Cited from every project's docs. |
| [THREAT-MODEL.md](THREAT-MODEL.md) | What we are trying to prevent. STRIDE-style enumeration scoped to AI governance evidence. |
| [POLICY-POSITIONS.md](POLICY-POSITIONS.md) | Public stances the Foundation will defend in regulatory comment letters and standards work. |
| [RELEASE-CALENDAR.md](RELEASE-CALENDAR.md) | Forward-looking dates for Umbrella releases, Beacon releases, and framework-registry refreshes. |

These documents have **lower velocity** than the rest of the repo. Updates require Foundation board sign-off (recorded in the PR).
